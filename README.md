# Aurora North

A single-page Northern Lights trip comparison for February 2027 from Berlin.

## Run locally
Open `index.html` in any browser. No build step or dependencies.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `aurora-north`.
2. Upload `index.html` (and this README) to the repository root.
3. In GitHub open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will publish the site at your GitHub Pages URL.
